# Michael Hardy's ™ Internet Spirit Web Browser!® v2.2.0

## Animated cursor/native pointer
- The normal operating-system pointer/hand is hidden whenever Internet Spirit animated cursors are enabled.
- Cursor suppression is now injected into all guest frames, including cross-origin iframe controls and security-verification frames.
- Shadow-root controls receive cursor suppression where an open shadow root can be reached.

## PNG scrollbar skin engine
- Added user-replaceable PNG scrollbars to every skin.
- Vertical/horizontal track images.
- Normal/Hover/Active vertical and horizontal thumb images.
- Up/Down/Left/Right button PNGs.
- Corner PNG.
- Active scrollbar PNGs are also injected into guest web-content frames as data URLs.

## Windows XP color toolbar / hover support
- Added new built-in `Windows XP Color Toolbar` skin inspired by the colorful classic toolbar reference.
- Added classic Windows XP-style hot tracking to built-in and user-made skins.
- A skin can choose `toolbarDefaults.effectStyle = "windows-xp"`.
- Existing Normal/Hover/Hot/Pressed/Disabled PNG state support remains.
- Added toolbar-effect-style choices: Skin Defined / Windows XP Classic / Image States Only.
