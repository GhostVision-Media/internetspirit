# Feature Matrix

## Browser Core
- Multi-tab browsing
- Omnibox search/address entry
- New-tab speed dial
- New-window links redirected to tabs
- Back/forward/reload/stop/home
- Favicon and page title tracking
- Zoom 50%-250%
- Find in page
- Full-screen
- DevTools
- External protocol launch

## Power Browser UI
- Classic menu strip
- Favorites bar
- Scrollable tab strip
- Sidebar tool center
- Status bar
- Link target preview
- Quick skin button
- Download center
- Session center

## Personal Data
- Bookmarks persisted as JSON
- History persisted as JSON
- Session restore
- Closed-tab list
- Settings persistence
- Optional clear browser storage action

## Skinning
- Manifest-based skin packages
- Runtime CSS variable replacement
- Optional arbitrary advanced CSS
- Built-in skins
- User skin directory
- Hot refresh
- Toolbar graphic overrides through CSS
- Fonts, radii, borders, chrome panels, tabs and sidebar are themeable

## Privacy/Control
- Basic ad/tracker URL blocker
- Blocker on/off toggle
- Dedicated persistent browser partition
- Host renderer uses context isolation and no Node integration


## Animated Cursor System (v1.0.8)
- Skin-pack animated cursor manifests
- GIF / animated WebP / APNG cursor artwork
- Frame-sequence animation support
- Browser-chrome cursor overlay
- Webview/website cursor tracking through guest preload IPC
- Normal / Link / Text / Busy / Drag / Resize-EW / Resize-NS roles
- Per-role size and hotspot settings
- User option to disable animated cursors instantly

- Top-layer animated cursors remain visible over modal browser dialogs
- Compact Spirit Neon cursor pack with Tiny / Compact / Standard sizing

- 150 additional image-driven themes with toolbar icons, background art, titlebar art, splash art, and progress-bar art
